# Resource-Aware Agentic AI

Research internship project focused on optimizing token usage, communication efficiency and computational resource utilization in multi-agent AI systems.

## Project Objectives

- Study multi-agent AI workflows
- Analyze token consumption and communication overhead
- Explore resource optimization techniques
- Implement efficient orchestration strategies
- Benchmark optimized workflows

## Technologies

- Python
- LangChain
- CrewAI
- OpenAI API
- Multi-Agent Systems

## Repository Structure

- papers/ → Literature review and research notes
- src/ → Source code and implementation
- presentations/ → Internship presentations and reports

## Internship Focus

The project focuses on developing resource-aware agentic AI systems capable of efficient multi-agent coordination while reducing token usage, latency and communication overhead.
